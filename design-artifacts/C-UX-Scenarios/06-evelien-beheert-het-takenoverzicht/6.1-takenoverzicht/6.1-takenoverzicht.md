## Overview

**Page Purpose:** Evelien ziet al haar openstaande taken, gegroepeerd per week en gesorteerd op deadline, en vindt de taak die ze wil aanpassen.

**User Situation:** Hoort of herinnert zich dat een taak is veranderd (deadline verschoven, opdracht bleek lastiger) en wil dat corrigeren zodat de planning weer klopt.

**Success Criteria:** Ze vindt de juiste taak zonder te zoeken of zich te vergissen tussen een lange lijst.

**Entry Points:**
- Hamburgermenu, vanaf elk scherm

**Exit Points:**
- Tikt op een taak → 6.2-taakdetail (primair)
- Tikt op "+ Nieuwe taak" → 2.1-taak-formulier (secundair, scenario 02)
- Tikt "← Terug" → vorige pagina (secundair)

## Layout Structure

Eén kolom: uitweg + "+ Nieuwe taak" bovenaan, daaronder taken gegroepeerd per week, gesorteerd op deadline binnen elke groep.

```
┌────────────────────────────────────┐
│  ← Terug           [+ Nieuwe taak] │
│                                      │
│  Takenoverzicht                     │
│                                      │
│  Deze week                          │
│  ┌──────────────────────────────┐   │
│  │ WISKUNDE · Proefwerk          │   │
│  │ Hoofdstuk 4: Vergelijkingen   │   │
│  │ ▓▓▓▓░░░░  2 van 4 subtaken    │   │
│  └──────────────────────────────┘   │
│  ┌──────────────────────────────┐   │
│  │ GESCHIEDENIS · Opdracht       │   │
│  │ H5 lezen                      │   │
│  │ ░░░░░░░░  0 van 1 subtaken    │   │
│  └──────────────────────────────┘   │
│                                      │
│  Volgende week                      │
│  ┌──────────────────────────────┐   │
│  │ BIOLOGIE · SO                 │   │

│  │ (geen subtaken)               │   │
│  └──────────────────────────────┘   │
└────────────────────────────────────┘
```
