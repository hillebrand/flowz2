# 7.1-weekoverzicht

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 07: Evelien Bekijkt de Weekplanning |
| **Page Number** | 7.1 |
| **Platform** | Desktop (primair) — ook bruikbaar op Mobile, met minder onderdelen tegelijk zichtbaar (verkorte weergave) |

## Overview

**Page Purpose:** Evelien ziet in één oogopslag hoe de komende week ervoor staat, en wordt actief gewezen op knelpuntdagen met een concrete oplossing.

**Entry Context:** Via het hamburgermenu, vanaf welk scherm dan ook.

**Exit Action:** Accepteert een suggestie voor een knelpuntdag, of verlaat het scherm zonder knelpunten — scenario succes ✓

**On-Page Interactions:**
- Per dag van de komende week: beschikbare tijd en benodigde tijd bekijken (cijfers, geen balk)
- Per dag de ingeplande taken/sessies bekijken
- Overige Google Calendar-items bekijken, puur indicatief (niet bewerkbaar op dit scherm)
- Knelpunt-dagen (te weinig beschikbare t.o.v. benodigde tijd) worden gemarkeerd, met een concrete oplossingssuggestie (zelfde aanbevelingslogica als scenario 03: herplannen / tijd verruimen / inkorten op prioriteit)
- Een suggestie direct accepteren om het knelpunt op te lossen

## User Situation (Q3)

Aan het begin van de week (bijv. zondagavond) wil ze een beknopt beeld krijgen van hoe druk de komende week wordt, zonder er zelf iets voor te hoeven uitrekenen.

## Mental State (Q4)

**Hope:** Dat Flowz haar direct wijst op een probleemdag mét een concrete oplossing, in plaats van dat zij zelf de cijfers moet interpreteren.

**Worry:** Een drukke dag over het hoofd zien omdat ze de cijfers zelf niet goed doorgrondt.

## Discovery Method (Q6)

Via het hamburgermenu opent ze het weekoverzicht.
