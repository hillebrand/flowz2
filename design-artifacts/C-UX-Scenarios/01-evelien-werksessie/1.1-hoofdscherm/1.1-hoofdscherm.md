## Overview

**Page Purpose:** Evelien ziet zonder enige actie de eerstvolgende taak en start de bijbehorende werksessie — met net genoeg context (resterende tijd, eventuele tijdsdruk, rest van de dag) om vertrouwen te geven, zonder overweldigd te raken.

**User Situation:** VWO 3-scholiere, doordeweekse avond na het eten. Ze moet nog huiswerk doen voor morgen en heeft niet de energie om zelf uit te zoeken wat prioriteit heeft.

**Success Criteria:** Evelien ziet de eerstvolgende taak en start de sessie zonder te hoeven zoeken, scrollen of nadenken (kerndoel-metric: Evelien's rustige planningservaring).

**Entry Points:**
- Opent de Flowz-app op een doordeweekse avond, direct na het eten

**Exit Points:**
- Tikt op "Start sessie" → 1.2-sessie-tussenscherm (primaire exit-actie)
- Tikt op een taak in "Later vandaag" → start direct een sessie voor die taak → 1.2-sessie-tussenscherm (secundair — bv. als een benodigdheid voor de eerstvolgende taak ontbreekt)
- Tikt op hamburger-icoon → navigatiemenu (secundair)
- Tikt op "Vandaag niet als gepland?" → 3.1-reden-kiezen (secundair — alleen als de dag daadwerkelijk niet volgens plan gaat)

## Layout Structure

Eén kolom bovenaan (Header, conditionele Waarschuwing-banner, primaire Taakkaart), daaronder een tweekoloms rij met secundaire context (compacte takenlijst + Google Calendar-dagweergave).

```
┌────────────────────────────────────────────────────────────────┐
│  ☰                         Flowz                    3u20m/5u    │
├────────────────────────────────────────────────────────────────┤
│  ⚠  Let op: voor deze sessie is er vandaag weinig tijd over     │
├────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  Wiskunde                                                 │ │
│   │  Hoofdstuk 4: Vergelijkingen oefenen                      │ │
│   │  ⏱ 25 min                                                 │ │
│   │                                        [ Start sessie ]    │ │
│   └──────────────────────────────────────────────────────────┘ │
│                                     Vandaag niet als gepland?   │
│                                                                  │
├──────────────────────────────┬─────────────────────────────────┤
│  Later vandaag        ↕scroll │  Vandaag                        │
│  · Engels — samenvatting      │  15:00 ──────────                │
│  · Geschiedenis — H5 lezen    │  16:00 ▓▓▓ Tennis                │
│  · Biologie — begrippen leren │  17:00 ──────────                │
│  · ...                        │  18:00 ▓▓▓ Avondeten             │
│                                │  19:00 ──────────                │
└────────────────────────────────────────────────────────────────┘
```

De "Later vandaag"-kolom toont **alle** taken van vandaag (niet slechts een selectie) in een vaste maximumhoogte met interne scroll — zo blijft het scherm zelf altijd even hoog, ook op een drukke dag.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Taakdata + Google Calendar succesvol geladen | Taakkaart, tijd-indicator, "Later vandaag"-lijst (scrollbaar bij veel taken) en kalenderdagweergave gevuld; waarschuwing-banner conditioneel | Start sessie, hamburger-menu, taak starten vanuit "Later vandaag" |
| Laden | Direct na openen, voordat taakdata/Calendar-data binnen zijn | Subtiele skeleton i.p.v. spinner — voorkomt onrustig gevoel bij openen | Geen (wachten) |
| Leeg | Geen eerstvolgende taak (alles gedaan of niets gepland) | Geen taakkaart — rustige, positieve boodschap (bv. "Je bent klaar voor vandaag!"), geen "Start sessie"-knop. "Later vandaag"-lijst toont eigen leeg-bericht indien ook leeg. | Hamburger-menu blijft beschikbaar |
| Fout (Calendar) | Google Calendar API faalt of timeout | Taakkaart blijft gewoon werken (kernfunctie hangt niet af van Calendar). Kalenderdagweergave: "Kan agenda niet laden". Waarschuwing-banner verschijnt **niet** (fail-safe — geen ongefundeerde tijdswaarschuwing) | Start sessie blijft beschikbaar |

## Responsive Behavior

### Mobile (< 768px)

**Layout Changes:**
- Zelfde verticale volgorde (Header → Waarschuwing → Taakkaart → secundaire rij)
- "Later vandaag" en "Dagplanning" niet meer naast elkaar maar onder elkaar gestapeld, of kalenderdagweergave ingeklapt/scrollbaar

**Mobile-Specific:**
- Kortere/verkorte weergave conform scenario-device-notitie ("minder onderdelen tegelijk zichtbaar")

### Desktop (> 1024px)

**Full Layout:**
- Volledige tweekoloms rij (Later vandaag + Dagplanning naast elkaar), zoals in de schets

### Component Breakpoint Behavior

| Component | Mobile | Desktop |
|-----------|--------|---------|
| `home-secondary-row` | Verticaal gestapeld / kalender ingeklapt | Horizontaal, twee kolommen |
| `home-header-time-indicator` | Mogelijk verkort (alleen resterende tijd, kleiner lettertype) | Volledig zichtbaar |
