## Overview

**Page Purpose:** Evelien doorloopt de werksessie — timer loopt, ze werkt subtaken (indien de taak die heeft) één voor één af, met de mogelijkheid te pauzeren of te stoppen.

**User Situation:** Komt net van 1.2-sessie-tussenscherm, klaar om te beginnen (of keert terug op deze pagina na een pauze).

**Success Criteria:** De sessie verloopt zonder wrijving; bij stoppen herplant Flowz automatisch zodat Evelien niets zelf hoeft uit te zoeken.

**Entry Points:**
- Vanaf 1.2-sessie-tussenscherm: "Start"-knop

**Exit Points:**
- Tikt op "Stoppen" → 1.4-sessie-afronden (enige exit-actie van deze pagina)

## Layout Structure

Bovenste rij: voortgang (timer, pauze, subtaak-teller) links, "Stoppen" rechts — altijd zichtbaar. Daaronder, gecentreerd: de huidige subtaak (of niets, als de taak geen subtaken heeft).

```
┌──────────────────────────────────────────────┐
│  ⏱ 12:34    Subtaak 2 van 4        Stoppen   │
│  [ Pauzeren ]                                 │
│                                                │
│                                                │
│           Opgave 4.1 t/m 4.6 maken            │
│                                                │
│                                                │
│                [ Klaar ]     [ Later ]        │
└──────────────────────────────────────────────┘
```

**Variant — taak zonder subtaken:** geen subtaak-sectie, geen voortgangsindicator, geen "Alle subtaken klaar"-melding. Bovenste rij (Timer, Pauzeren, Stoppen) blijft; in het midden tonen vak + taaknaam als context, zodat het scherm niet leeg aanvoelt.

**Variant — alle subtaken klaar:** subtaak-sectie vervangen door een "Alle subtaken klaar!"-melding, "Klaar"/"Later" niet meer aanwezig.

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Actief (default) | Sessie loopt, taak heeft subtaken | Timer loopt, voortgangsindicator, subtaak-info, "Klaar"/"Later", "Stoppen" | Klaar, Later, Pauzeren, Stoppen |

## Technical Notes

- **Herplanning gebeurt niet op deze pagina.** "Stoppen" (en de wegnavigeer-varianten) logt alleen de sessie. De daadwerkelijke herplanning triggert pas bij het verlaten van 1.4-sessie-afronden, ná een eventuele handmatige aanpassing van de resterende tijd door Evelien — zie 1.4 voor die interactie. Reden: als herplanning al bij "Stoppen" zou gebeuren, veroudert die zodra ze op 1.4 de resterende tijd aanpast.
- **Open punt (sendBeacon-pad):** als Evelien het tabblad sluit terwijl de sessie loopt, bereikt ze 1.4 nooit — de herplanning die normaal bij het verlaten van 1.4 gebeurt, wordt dan niet getriggerd door haarzelf. Moet de server in dat geval automatisch herplannen op basis van de oorspronkelijke schatting (dus zonder de kans op handmatige aanpassing die 1.4 normaal biedt)? Zie Open Questions.
- Herplanningslogica hergebruikt waarschijnlijk dezelfde onderliggende service als scenario 07/08's automatische achtergrond-herplanning.
- Sessie-logging (bestede tijd, subtaken-status) is nodig als datamodel-input voor 1.4-sessie-afronden.
- Een taak kan over meerdere sessies lopen — datamodel is taak → sessies (1:N), niet taak → sessie (1:1).
