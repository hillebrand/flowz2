# 1.3-sessie-actief

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 01: Evelien's Werksessie |
| **Page Number** | 1.3 |
| **Platform** | Desktop (primair) — ook bruikbaar op Mobile, met minder onderdelen tegelijk zichtbaar (verkorte weergave) |

## Overview

**Page Purpose:** Evelien doorloopt de werksessie — timer loopt, ze werkt subtaken één voor één af, kan pauzeren.

**Entry Context:** Komt van 1.2-sessie-tussenscherm — tikte op "Start".

**Exit Action:** Tikt op "Afronden" → gaat naar 1.4-sessie-afronden.

**On-Page Interactions:**
- Subtaak **afronden** — volgende subtaak verschijnt, blijft op deze pagina
- Subtaak **uitstellen** — volgende subtaak verschijnt, de uitgestelde subtaak komt later in de sessie terug, blijft op deze pagina
- Sessie **pauzeren** — timer stopt, progress bar bevriest, blijft op deze pagina
- Geplande sessietijd verstreken — sessie blijft actief zodat ze door kan werken zonder actie te ondernemen (visueel signaal), blijft op deze pagina
