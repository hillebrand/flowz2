# 1.4-sessie-afronden

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 01: Evelien's Werksessie |
| **Page Number** | 1.4 |
| **Platform** | Desktop (primair) — ook bruikbaar op Mobile, met minder onderdelen tegelijk zichtbaar (verkorte weergave) |

## Overview

**Page Purpose:** Evelien ziet het afrondingsoverzicht van de sessie — gepland vs. besteed vs. resterend, voortgang op subtaken — en kan de resterende benodigde tijd bijstellen.

**Entry Context:** Komt van 1.3-sessie-actief — tikte op "Afronden".

**Exit Action:** Terug naar 1.1-hoofdscherm — scenario succes ✓ (de volgende taak staat daar al klaar).

**On-Page Interactions:**
- Totale geplande tijd, bestede tijd, resterende tijd bekijken
- Voortgang op subtaken bekijken (aantal afgerond vs. totaal, details inklapbaar)
- Resterende benodigde tijd aanpassen
- Melding zien als het aantal afgeronde subtaken afwijkt van de verwachting
